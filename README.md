# Prodigy Generative AI - Task 05

## Neural Style Transfer using TensorFlow Hub

This project demonstrates Neural Style Transfer, a deep learning technique that combines the content of one image with the artistic style of another image.

### Technologies Used
- Python
- TensorFlow
- TensorFlow Hub
- NumPy
- Matplotlib
- Google Colab

### Implementation
- Imported and configured the required libraries.
- Loaded a pretrained Neural Style Transfer model from TensorFlow Hub.
- Selected a content image and a style image.
- Preprocessed both images and passed them to the model.
- Generated a stylized image by applying the artistic style to the content image.
- Saved the generated output image.

### Model
Google Magenta Arbitrary Image Stylization Model

### Output
Generated an artistic image by combining the content of a beach sunset photograph with the style of a Starry Night-inspired painting.
